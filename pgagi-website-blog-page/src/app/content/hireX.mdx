# AI Recruiter Project Interfaces and Workflow

## Overview
The AI recruiter project leverages advanced AI technologies to automate the recruitment process across three distinct user interfaces. Each interface serves a specific function in the recruitment process, from gathering job requirements to managing candidate data.

## User Interfaces

### 1. User Interface for Companies
- **Functionality**: Tailored for companies to input job requirements.
- **Features**: Includes a chatbot powered by GPT-4 for detailed job requirement collection.
- **Process**: Triggers recruitment agents to start searching for candidates upon job ID creation.

### 2. Candidate Interface
- **Functionality**: Allows candidates to upload resumes and contact details.
- **Process**: Candidates can receive interview calls or scheduling notifications post-registration.

### 3. Admin Portal
- **Functionality**: Used by the Hirextra team to manage all user and candidate data.
- **Features**: Includes a human-in-the-loop feature to upload offline profiles.
- **Process**: Provides support and oversees the recruitment cycle, ensuring no candidate is missed.

## Operational Workflow
- **Candidate Search**: Agents use Google and LinkedIn to find and extract candidate data.
- **Candidate Engagement**: Engages candidates via email to register on the Candidate Interface.
- **Interview Management**: Uses the TOINGG AI calling agent for scheduling and conducting interviews.
- **Admin Oversight**: The admin portal allows for manual intervention if automated searches fail.

## Monitoring and Support
- Companies can monitor the recruitment process in real-time through the User Interface, including seeing profiles of candidates currently interviewed by the TOINGG AI calling agent.

This system enhances recruitment efficiency and ensures high engagement levels with companies and candidates, improving talent acquisition success.
