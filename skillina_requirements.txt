• Doesn’t distinguish symptom from possible cause.
“Our engagement on collaboration tools is down, so I’d ask engineering to fix bugs or refresh the UI—something is broken.”

Emerging (40–60%)
• Raises a few clarifying questions (“Is this a one-time dip or trend? Which feature specifically?”).

• Starts separating symptom from potential root drivers but remains at a surface level.
“I’d check usage logs to see if it’s just polls or all features, and I’d ask whether mid-sized teams are hitting a performance issue. Maybe it’s seasonality, or maybe the UI is confusing.”

Strong (60–80%)
• Quickly scopes to a clear statement: “Feature-usage is down month-over-month among mid-sized teams.”

• Lays out a hypothesis structure (“Quantify drop → validate with user feedback → isolate root causes”).


• Uses multiple responses in the interview to refine this framing.
“First, I’d confirm which in-meeting tools have the steepest adoption decline—polls dropped 25 % in six months at mid-sized accounts—and check if that correlates with churn risk. Then I’d surface potential drivers (e.g., UX discoverability, performance lag, or shifting user behavior) and build root-cause hypotheses we can test.”

Elite (>80%)
• Anticipates downstream impacts on retention and revenue pipeline (“This drop risks a 10 % retention loss in Q3”).

• Frames root causes in broader context (e.g., competitor moves, market shifts) while still focusing on the current problem scope.


• Integrates signals from multiple questions (qualitative, quantitative, long-term vision) to produce a crisp, single‐sentence problem statement with 1–2 testable hypotheses.
“I’d frame the core problem as: ‘Mid-market teams are abandoning collaboration features because they don’t see immediate ROI—reflected by a 30 % drop in polls over six months—which is driving a 12 % lift in churn-scored support tickets. This likely stems from both a UX disconnect (feature hidden) and a behavior shift where competitors’ solutions auto-suggest collaboration. Our hypothesis: if we optimize discoverability and reintroduce in-session coaching, we should see a ≥20 % adoption lift and mitigate churn risk.”

STOPWORDS_MUST_HAVES = {
    'experience', 'background', 'knowledge', 'expertise', 'skills',
    'proficiency', 'familiarity', 'understanding', 'ability',
    'strong', 'excellent', 'good', 'solid', 'proven', 'demonstrated',

    'working', 'managing', 'leading', 'handling', 'developing', 'building',
    'with', 'in', 'of', 'the', 'and', 'or', 'a', 'an', 'for', 'to'
}

def clean_must_have(text):
    words = text.lower().split()
    filtered = [w for w in words if w not in STOPWORDS_MUST_HAVES]
    return ' '.join(filtered)
