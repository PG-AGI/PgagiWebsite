# AI Interviewer Using Mistral 7b Architecture



## Project Overview

### Introduction

The AI Interviewer project was initiated to create an advanced AI model that could function as an interviewer, providing insightful feedback on interview conversations. The project utilized the Mistral 7b model, which was fine-tuned on synthetic data generated via GPT-3 due to the absence of specific real interview data.

### Objective

Develop an AI that can autonomously conduct interviews and provide constructive feedback, thereby supporting HR departments in screening candidates more effectively.



## Role and Responsibilities

Our responsibilities encompassed overseeing the data generation process, model training, and the evaluation of the model's performance.

### Responsibilities

- Designed and implemented a Python script for generating synthetic interview data.
- Utilized GPT-3.5 Turbo to create diverse and realistic interview scenarios.
- Fine-tuned the Mistral 7b model using AWS SageMaker.
- Developed metrics to evaluate the model's feedback accuracy and relevance.



## Tools and Technologies Used

- **Programming Languages**: Python
- **AI Models**: OpenAI GPT-3, Mistral 7b
- **Platforms and Services**: AWS SageMaker, Hugging Face
- **Others**: Git for version control, Jupyter Notebooks for scripting and testing

## Data Collection and Generation

### Challenges in Data Acquisition

- Initial attempts to source real interview data faced challenges due to privacy concerns and data availability.

### Solution

- A decision was made to generate synthetic data, which involved:
  - Creating a Python script that leverages GPT-3 to simulate interview dialogues.
  - Ensuring a wide range of scenarios, personalities, and roles to enhance the diversity and richness of the dataset.



## Model Training and Fine Tuning

### Process

- Start with pre-trained Mistral 7b weights.
- Conduct multiple fine-tuning iterations on the synthetic dataset within AWS SageMaker.
- Regularly adjust parameters and training strategies based on ongoing results and evaluations.



## Model Evaluation

### Performance Evaluation

The model was tested against a set of performance metrics designed to assess:

- The relevance of feedback provided by the AI.
- The ability of the AI to understand and respond to various interview contexts.
- The overall usability of the AI in a real-world HR setting.



## Achievements and Outcomes

- Developed an AI capable of autonomously conducting and evaluating interviews.
- Proved the efficacy of using synthetic data for training AI in scenarios where real data is scarce.
- Enabled the potential reduction of preliminary screening times in recruitment processes.
