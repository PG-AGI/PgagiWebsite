# Automated Trading Agent for cTrader to MT5 Integration
![Trading Agent](https://i.postimg.cc/6Q5ckDkJ/Automated-Trading-Agent-for-c-Trader-to-MT5-Integration1.png)


## Overview

This project involved the creation of an automated AI agent designed to facilitate trading operations between the cTrader and MetaTrader 5 (MT5) platforms. By leveraging Optical Character Recognition (OCR) technology, the agent is capable of interpreting visual data from the trading interfaces, enabling seamless trade execution and data transfer across different trading systems.



## Technical Stack

- **OCR Technology**: Utilized for capturing and interpreting interface data, enhancing the agent’s ability to interact with the trading platforms.
- **Selenium**: Employed to automate web browser interactions, facilitating accurate and efficient data retrieval and control within trading platforms.
- **OpenAI Vision Model**: Integrated to enhance image recognition capabilities, further improving the accuracy of data extraction and analysis from the trading interfaces.
- **AI/Machine Learning**: Algorithms implemented to make real-time trading decisions based on data derived from OCR.
- **Integration Tools**: Custom scripts and APIs developed for robust data exchange between cTrader and MT5.
- **Programming Languages**: Employed Python for its powerful libraries in AI and OCR, and C# for integrating with trading platform APIs.

## Project Execution

The project commenced with an in-depth analysis of the trading platforms' interfaces, followed by the development of an OCR module to accurately capture and convert visual data into actionable formats. Subsequent phases involved training machine learning models to predict trading signals based on historical data. The final stage focused on creating a seamless connection between cTrader and MT5, ensuring reliable data synchronization and trade execution.

This automated agent significantly optimizes the trading workflow, reduces manual errors, and accelerates decision-making processes, providing a competitive edge in fast-paced trading environments.
